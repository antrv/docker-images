# Repository instructions

Read [README.md](README.md) for image documentation, usage examples, and build metadata conventions.

- Keep changes focused on the requested image or feature and follow existing conventions.
- Update the relevant documentation when changing image versions or user-facing behavior; avoid duplicating documentation.
- Keep shell scripts compatible with their declared interpreter and use LF line endings.
- Validate changed scripts and build affected images when Docker is available. Report any checks that could not be run.
